# magazine-PDF-hebdomadaire-d-actualit-s-IA-avec-OpenAI-RSS-et-Gmail
Ce flux de travail fonctionne chaque lundi matin, extrait les derniers gros titres sur l’intelligence artificielle d’un flux RSS de Google News, utilise OpenAI pour concevoir un magazine HTML stylisé « Weekly Insider », le convertit en filigrane PDF via HTMLCSS vers PDF, puis l’envoie par email aux abonnés via Gmail.
